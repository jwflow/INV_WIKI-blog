# Anthropic 투자 방법 — RWA 토큰 vs 안전한 우회 접근

> 소스: raw/youtube/2026-06-03T161700+0900_비트코인 무조건 깨집니다 (강환국 작가 2부)

---

## 투자 thesis

Anthropic은 현재 비상장이지만 OKX 등 해외 코인 거래소에서 RWA 토큰 형태로 선취 투자 가능. 상장 시 토큰 가격이 주식 가격에 수렴하므로, 현재 디스카운트 구간이 기회. 단, 거래소 리스크가 핵심 변수.

## RWA 구조 이해

```
Anthropic (비상장사)
    ↓  실물 자산 토큰화 (RWA)
OKX · 하이퍼리퀴드 등 해외 거래소
    ↓  선물 형태로 24시간 거래
투자자 매매 가능
    ↓  Anthropic IPO 시
토큰 가격 ↔ 주식 가격 수렴
```

**같은 방식으로 거래 가능한 자산**:
- OpenAI (OKX 등)
- SpaceX (OKX 등)
- 삼성전자·SK하이닉스 (하이퍼리퀴드)

## RWA 투자 장점 (강환국 발언 기반)

| 장점 | 설명 |
|---|---|
| 24시간·7일 거래 | 주말·공휴일 없음. 주말 뉴스에 즉시 대응 가능 |
| 현재 세금 없음 | 코인 형태라 현재 과세 대상 아님 (한국 기준) |
| 환전 불필요 | 보유 코인(USDT·USDC)으로 바로 매수 가능 |
| 레버리지 가능 | 최대 20배 (권장하지 않음) |
| 상장 전 선취 | 비상장 프리미엄 수익 가능 |

## 리스크 — 강환국이 직접 경고한 것

> "거래소가 일단 지금은 코인 거래소의 리스크가 가장 크다."

| 리스크 | 내용 | 심각도 |
|---|---|---|
| **거래소 파산** | FTX처럼 문 닫으면 자산 전액 손실. 구제 수단 없음 | ★★★★★ |
| **비상장 불확실성** | 상장 안 할 수도 있음. 밸류에이션 변동 가능 | ★★★★☆ |
| **유동성 리스크** | LP(유동성 공급자)가 가격 형성. 변동성 극심 가능 | ★★★☆☆ |
| **규제 리스크** | OKX는 국내 미인가 거래소. 법적 보호 없음 | ★★★★☆ |
| **세금 변화** | 향후 과세 가능성 높음 | ★★★☆☆ |

**강환국 권고**: 거래소 분산. 한 거래소에 몰빵 금지.

## 비판적 평가 (펀드매니저 시각)

### 긍정

- Anthropic IPO 시 $4,000 수렴 논리는 타당 — 현재 $1,800은 약 55% 디스카운트
- AI 에이전트 시대의 핵심 기업에 비상장 단계에서 선취하는 구조
- 강환국 본인 실행 + 수익 발생($1,600→$1,800) — 검증된 방법

### 부정

1. **"베프라서 샀다"** — 감정적 투자 동기. 투자 thesis로는 부족. 팬심과 투자 판단 혼재
2. **OKX = 국내 미인가 거래소** — FTX 파산 시 100% 손실 사례 실재. 법적 보호 전무
3. **가격 형성 불투명** — 시장참여자들끼리 합의한 가격. 실제 Anthropic 밸류에이션과 괴리 가능
4. **유동성 공급자(LP) 문제** — 가격 조작 가능성 배제 불가
5. **현재 세금 없음 = 일시적** — 과세 시행 시 소급 적용 위험

## 투자 결론

### Anthropic RWA 토큰 (OKX)

> **소액·감당 가능한 금액 범위(포트폴리오 2~3% 이내)에서만 접근 가능.**

- 날릴 각오를 한 금액으로만 진입
- 거래소는 OKX + 하이퍼리퀴드 등 최소 2곳 분산
- 레버리지 절대 사용 금지 (1배)
- 상장 뉴스 → 청산 계획 미리 수립

### 더 현명한 방법

> **Anthropic에 베팅하면서 잠을 잘 자고 싶다면 → GOOG 보유가 정답.**

GOOG는 Anthropic에 직접 투자한 주주이며, AI·클라우드·SpaceX 지분을 동시에 보유한 종합 선물 세트. 거래소 파산 리스크 없이 Anthropic 성장에 간접 노출.
