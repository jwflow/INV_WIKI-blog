# output/synthesis/ 운영 규칙

다수 소스(YouTube 영상, 리서치, 뉴스)를 교차검증하여 통합 인사이트를 산출하는 폴더다.

## 파일 명명

`YYYYMMDD_주제_종합분석.md`

예: `20260603_크립토항공우주_종합분석.md`

## 작성 원칙

1. 최소 3개 이상의 소스를 교차검증
2. **화자 간 불일치**를 명시적으로 표시하고 어느 주장이 더 신뢰성 높은지 평가
3. **1조 원 이상 펀드매니저 시각** 유지 — 낙관·확증편향 경계
4. 결론은 구체적 액션(매수/관망/회피)으로 마무리
5. 새로운 소스 ingest 시 기존 synthesis 보고서 업데이트 또는 신규 발행

## 생성 조건

- 동일 테마의 YouTube 영상 3개 이상 ingest 완료 시
- 상충하는 주장이 발견될 때
- 사용자 Query 시
