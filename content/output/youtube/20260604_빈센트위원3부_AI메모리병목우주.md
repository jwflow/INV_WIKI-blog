## 주요 논거

### 1. 메모리 반도체 — 끝나지 않은 병목

- "메모리가 비싸니까 NAND를 쓰는 것. 메모리가 싸면 다 메모리 씀"
- AI 학습(HBM+GPU) → **AI 인퍼런스(저지연 응답)**: GPU+HBM 필요
- **피지컬 AI·로봇**: 로봇의 눈으로 보는 모든 것을 저장·처리 → 메모리 수요 비약적 증가
  - "아틀라스 하나의 휴머노이드 로봇이 매일 보는 것을 다 기억하고 조정해야 한다"
- 장기 멀티플 상승 가능성: 메모리 수요 구조 확인 시 "지금보다 4~5배" 논리

### 2. 전력 인프라 + 원전

- 젠슨 황 피라미드: 모든 AI 수요의 하단 = 전력
- 에너지 공급 우선순위: 석탄(즉각) → 태양광/재생에너지(빠름) → 원전(대용량, 10년+)
- **원전주 핵심**: "실적이 찍혀야 주가 모멘텀 재발동" — 기대감은 이미 반영, 수주 확인이 트리거
- 전력 부족으로 데이터센터 건설 딜레이 현상 = 실재하는 리스크 (단기 주가 민감)

### 3. SpaceX IPO + 테슬라 합병 가능성

- "300페이지 S1 보면 테슬라와 합병 눈앞에 두고 있다" (⚠️ 독립 검증 필요)
- SpaceX **최고 KPI = 우주 데이터센터** (강정수 박사 2부와 일치)
- 우주 데이터센터: 냉각 자유, 효율 극대화 → 막대한 초기 자금 → IPO로 조달
- **밸류에이션**: $1.8조 달러 (강정수 박사 언급 $2조와 약간 차이 — 발표 시점 차이)
- 결론: "AI 관련 인프라(전기+데이터센터)를 지배하는 기업이 되는 것"

### 4. 로봇 — 산업 채택 vs 사회 수용 갭

- 산업용 상용화: "우리가 생각하는 것보다 빠를 수 있다"
- **사회적 수용**: 도덕, 휴머니티, 범죄 문제 → 국가마다 시간 차
- "2026 북미 월드컵 때 로봇 시연 기대감 → 실제 소비자 채택까지는 더 걸릴 것"
- 주도주 부상에 시간 필요: 반도체 다음 주도주로 우주·양자·피지컬AI 모두 경쟁

### 5. 코스닥 6월 중순 단기 카탈리스트

- **국민참여형펀드** 완판 → 집행까지 약 2주 → 6월 중순 코스닥 자금 유입 기대
- 다주택자 중과세 부활(5월 중순) → 부동산 자금 일부가 동산(주식)으로 이동
- 고객 예탁금 130조원 (풍부한 대기 자금)
- 단, 불확실성 환경에서 "확실히 돈 버는" 주도주 집중 현상 지속

### 6. 방산

- 마가(MAGA) + 마스카 중심 테마. 한국 방산 글로벌 경쟁력 인정
- **핵심 트리거**: 실제 수주 계약 확인 → 주가 모멘텀 재발동
- "좋은 산업 ≠ 좋은 주가 타이밍" — 수주 발표 전까지는 주춤

### 7. 네이버·카카오 — 부정적 시각

- 검색 플랫폼 경쟁력: Perplexity 등 AI 검색으로 대체 → 네이버 검색 사용 감소
- 카카오 채비(AI): "안 씀"
- 국가 주도 AI 드라이브 시 단기 모멘텀 가능하나, 글로벌 경쟁 열위
- 스테이블코인·결제 연계 시나리오(카카오페이, 네이버페이)는 단기 재료

### 8. BTC + ETH — 공포에 살 용기

- "코인이 안 좋은 건 알지만, 공포에 살 수 있는 용기가 필요"
- **추천**: BTC + ETH (스테이블코인 인프라 근간)
