# output/youtube/ 운영 규칙

YouTube 영상 1개당 분석 보고서 1개를 생성하는 폴더다.

## 파일 명명

`YYYYMMDD_화자성_핵심주제.md`

예: `20260603_인호교수_BTC전망.md`, `20260603_강환국_원자재BTC양자.md`

## 작성 원칙

1. **화자의 주장을 있는 그대로 먼저 기술**한 뒤 비판적 평가 분리
2. **투자자 관점 필터링**: 핵심 테마(AI·항공우주·화폐시스템 개혁)와의 관련성 중심
3. **비판적 평가** 섹션에서 반론·한계·과장 가능성 지적
4. **관련 종목·자산 영향**은 ▲/▼/— 방향성과 근거 함께 기재
5. raw 파일에 없는 transcript는 영상 설명·타임스탬프 기반으로 최대한 추론

## 생성 조건

raw/youtube/ 에 새 파일 ingest 시 자동으로 분석 보고서 생성.
relevance = high이면 wiki 자산·테마 페이지에도 반영.
